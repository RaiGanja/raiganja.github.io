# Хаб gabella.site — дизайн (этап 7)

Дата: 23.10.2026. Ветка: `hub/home`. Репо: `RaiGanja/raiganja.github.io` (локально `C:\Users\Inzagi\gabella-hub`).

## Цель

Корень `gabella.site/` сейчас — заглушка: `meta refresh` и canonical на `/wow/`, поэтому для Google это дубль гида. Вместо неё нужна **публичная витрина гидов**: своя страница со своим title, canonical и sitemap. С неё попадают в гид WoW Forever, и в неё же позже добавляются гиды по другим играм.

Ограничения:
- На странице нет ни слова про Discord, команду или друзей, нет упоминаний ИИ. Это витрина для поиска, а не страница клана.
- Нигде не анонсируем: решение о доходности принимаем 01.12.2026 по органике.
- `/wow/` (репо `RaiGanja/wow`) этим этапом не меняется.

## Решения

| Вопрос | Решение |
|---|---|
| Аудитория | Витрина гидов для всех |
| Состав | Только WoW Forever + его разделы + новости; плиток «скоро» нет |
| Языки | ru (`/`), en (`/en/`), uk (`/uk/`), как в гиде |
| Устройство | Свой сборщик в gabella-hub; ассеты берутся из гида по ссылке `/wow/assets/…` (вариант A) |
| Service worker | Не ставим: SW в корне управлял бы и `/wow/`, где уже свой SW |

## Страница сверху вниз

Стиль сайта «Icy Veins»: арт во всю ширину уходит в тёмный фон, поверх лежат панели со скруглением 10px, заголовки плиток стоят прямо на арте. Шрифты: Bona Nova SC 700 для заголовков и цифр, Golos Text для текста. Фон `#0a0b0d`, золото `#c9a54a`. Только тёмная тема.

Запрещено как «ИИ-слоп»: мелкие надписи-киккеры над заголовками, золотая черта под h2, контурные иконки в квадратиках, блоки с золотой полосой слева, бейджи на каждой строке.

1. **Шапка.** Слева логотип «Gabella» (иконка гида + слово), справа переключатель RU / EN / UK. Меню нет.
2. **Заголовок.** h1 «Гайды по играм» и одна строка о содержимом: разборы классов и рас, прокачка, подземелья, инструменты.
3. **Главная плитка WoW Forever.** На всю ширину, фон `hero_dawn` (на телефоне обрезка `hero_dawn-m-*`). Поверх: название, слово «Новое» золотом, отсчёт и кнопка «Открыть гид» → `/wow/` нужного языка.
   - До 04.11.2026 00:00 по локальному времени: «Релиз через N дн H ч», как в гиде.
   - После: «Вышла 04.11.2026», без отсчёта.
   - Без JS виден статичный текст «Релиз 04.11.2026».
4. **Быстрые входы.** 8 плиток с артом и заголовком на картинке. Ведут в ту же языковую версию гида (`/wow/`, `/wow/en/`, `/wow/uk/` + путь):
   - Классы — `classes/`
   - Расы — `races/`
   - Прокачка — `guides/leveling/`
   - Подземелья и рейды — `guides/dungeons/`
   - Профессии — `guides/professions/`
   - FAQ — `guides/faq/`
   - Новости — `guides/news/`
   - Инструменты — `tools/`

   На ПК сетка 4×2, на ≤1023px карусель scroll-snap. Арт каждой плитки — портрет класса или шапка из `/wow/assets/art/`, как у плиток гайдов на главной гида.
5. **Свежие новости.** Скрипт загружает `/wow/assets/news.json` и показывает 5 последних записей: дата и заголовок, ссылка на Wowhead в новой вкладке. В конце «Все новости» → `guides/news/` гида. Заголовки новостей английские на всех языках, подписи блока переведены. Пока данные грузятся, блок скрыт. Если запрос упал или пришёл пустой список, блок остаётся скрытым.
6. **Подвал.** © Gabella, ссылки на языки, ссылка на гид. Строка мелким шрифтом: «World of Warcraft — торговая марка Blizzard Entertainment. Сайт неофициальный, с Blizzard не связан» (на трёх языках).

**Следующая игра.** Новая запись в `GAMES` в `content.py`. Когда игр станет больше одной, главная плитка превратится в сетку игр. Этот код сейчас не пишем: в `build.py` проверяем, что игра в `GAMES` ровно одна, иначе сборка падает с понятной ошибкой.

## Файлы

```
gabella-hub/
  CNAME                    без изменений
  content.py               GAMES (WoW: название, арт, путь, 8 разделов) + T — тексты ru/en/uk
  index.src.html           шаблон: CSS и JS внутри, плейсхолдеры @@…@@
  build.py                 собирает index.html, en/index.html, uk/index.html, sitemap.xml, robots.txt
  index.html, en/, uk/     собранные страницы, коммитятся (Pages отдаёт как есть)
  sitemap.xml, robots.txt  собранные
  assets/og-{ru,en,uk}.jpg превью для ссылок
  tools/make_og.py         HTML со шрифтами → headless Chrome → jpg 1200×630
  tools/serve.py           локальное превью: хаб на /, ../wfpages на /wow/
  tests/check_site.py      проверки (ниже)
```

- **Ассеты гида.** Шрифты подключаются через `@font-face` с `/wow/assets/fonts/bona-nova-sc-*.woff2` и `golos-text-*.woff2`. Арт берётся из `/wow/assets/art/<name>-<w>.{avif,webp}` через `<picture>`. Favicon и apple-touch-icon — из `/wow/assets/icons/`. Пути абсолютные от корня домена, поэтому одинаково работают на всех трёх языках.
- **Шаблон.** Плейсхолдеры `@@LANG@@`, `@@TITLE@@` и т.п. Тексты подставляет `build.py` из `T[lang]`, переводы через i18n-файлы не нужны. Перед записью страницы `build.py` проверяет, что в ней не осталось ни одного `@@`.
- **Превью `tools/serve.py`.** Python `http.server` с обработчиком: `/wow/…` отдаёт из `../wfpages`, остальное — из хаба. Порт 8766, чтобы не столкнуться с превью гида на 8765.

## SEO

- **Title и description на каждом языке.** Например, ru: «Gabella — гайды по играм: WoW Forever», description про классы, расы, прокачку, подземелья и инструменты. Точные тексты лежат в `content.py`.
- **Canonical на себя.** `https://gabella.site/`, `…/en/`, `…/uk/`.
- **hreflang.** ru, en, uk и x-default (`/`) на всех трёх страницах.
- **Open Graph.** `og:title`, `og:description`, `og:image` (`assets/og-{lang}.jpg`) + `og:image:alt`, `og:locale` и `og:locale:alternate`, `twitter:card` summary_large_image.
- **JSON-LD.** `WebSite` с name «Gabella» и url, плюс `hasPart` → гид WoW Forever.
- **sitemap.xml хаба.** 3 URL, у каждого `xhtml:link` hreflang.
- **robots.txt.** `Allow: /` и две строки Sitemap: `https://gabella.site/sitemap.xml` и `https://gabella.site/wow/sitemap.xml`.
- **Аналитика.** В `build.py` константа `CF_BEACON_TOKEN = ''`, как в `seo.py` гида. Пока она пустая, сниппет не вставляется.
- **OG-картинка.** Тёмный фон `hero_dawn`, «Gabella» и «Гайды по играм · WoW Forever» на языке страницы, шрифты сайта.

## Проверки

`python tests/check_site.py` (флаг `--live` проверяет живой gabella.site):
- три страницы собраны, в них нет `@@`, у каждой правильный `lang`, canonical на себя и полный набор hreflang (ru, en, uk, x-default);
- у каждой страницы есть `og:image`, и этот файл лежит в `assets/`;
- `sitemap.xml` разбирается как XML и содержит 3 URL; в `robots.txt` две строки Sitemap;
- каждая ссылка и ассет на `/wow/…` из трёх страниц (шрифты, арт, иконки, разделы, `news.json`) отвечает 200 на `https://gabella.site`. Так ловим переименование файлов в гиде.

Перед сдачей проверяем запуском:
- скриншоты ПК 1440 и телефона 375 через headless Chrome (puppeteer-core в `%TEMP%\wflh`) на `tools/serve.py`;
- блок новостей показан с данными, а при недоступном `news.json` скрыт;
- Lighthouse mobile на главной: perf ≥ 95, без ошибок в консоли.

После выкладки:
- живой `gabella.site/`, `/en/`, `/uk/` отвечают 200, canonical стоит на себя;
- превью ссылки проверено как Discordbot;
- `/wow/` открывается и работает офлайн, как раньше: проверить, что SW гида не затронут.
